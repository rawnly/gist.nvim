*gist.txt*  GistCreate plugin

NAME
    gist - Create gists on GitHub, GitLab, Termbin, or SourceHut

SYNOPSIS
    :GistCreate
    :GistCreateFromFile
    :GistsList

DESCRIPTION
    The `:GistCreate` command creates a gist from the buffer selection or, if no range is given, from the full buffer contents (works on unnamed buffers too), using the configured platform's command-line tool.
    The `:GistCreateFromFile` command creates a gist from the current file using the configured platform's command-line tool.
    The `:GistsList` command lists all gists from your account on the configured platform and allows you to edit them (only supported on GitHub).
    
    When `list.use_multiplexer` is enabled and a multiplexer (tmux/zellij) is detected, gists are opened in new multiplexer tabs.
    Otherwise, gists are opened in read-only Neovim buffers for viewing.

    The plugin prompts you for a description and privacy settings for the gist creation (depending on the platform), and then copies the URL of the created gist to the system clipboard.

OPTIONS
    Both `:GistCreate` and `:GistCreateFromFile` accept multiple `key=value` arguments, in any order:

    description=<text>  Description for the gist. If omitted, the plugin will prompt for one (when prompts are enabled).
    public=true|false   Override the privacy setting. If omitted, the plugin uses the configured default or prompts.
    filename=<name>     Override the filename used for the gist. If omitted, the current buffer's filename is used; for unnamed buffers it falls back to the configured `default_filename` ("untitled" by default).

EXAMPLES
    To create a gist from the current file, run the following command in Neovim:

        :GistCreateFromFile description=hello public=true filename=snippet.lua

    The plugin will prompt you for a description and privacy settings for the gist (depending on the platform).
    After you enter the description and privacy settings, the plugin will ask for confirmation and create the gist using the configured platform's command-line tool and copy the URL of the created gist to the system clipboard.

    To create a gist from the current selection or, if no range is given, the full buffer contents (including unnamed buffers):

        :GistCreate description=hello public=true filename=snippet.lua
        :'<,'>GistCreate filename=excerpt.lua
